### Άσκηση 1

Γράψτε μία συνάρτηση η οποία θα παίρνει σαν παράμετρο ένα string και θα επιστρέφει ένα dictionary. Το string περιέχει ζεύγη `κλειδί=τιμή` χωρισμένα με `;`. Όλα τα κλειδιά και όλες οι τιμές μένουν string.

Η συνάρτηση θα πρέπει:
```python
print(f("a=b;k=5;rr=tt")) # Τυπώνει {'a': 'b', 'k': '5', 'rr': 'tt'}
print(f("x=1;y=2")) # Τυπώνει {'x': '1', 'y': '2'}
```

### Άσκηση 2

Γράψτε μία συνάρτηση η οποία θα παίρνει σαν παράμετρο ένα string και θα επιστρέφει μία λίστα από λίστες. Κάθε γραμμή του string έχει τη μορφή `όνομα[ακέραιος]`. Η επιστρεφόμενη λίστα περιέχει στοιχεία `[όνομα, ακέραιος]`, με τη σειρά των γραμμών.

Η συνάρτηση θα πρέπει:
```python
print(f("a[10]\nb[40]\nf[100]")) # Τυπώνει [['a', 10], ['b', 40], ['f', 100]]
print(f("gene[3]\nexon[12]")) # Τυπώνει [['gene', 3], ['exon', 12]]
```

### Άσκηση 3

Γράψτε μία συνάρτηση η οποία θα παίρνει σαν παράμετρο ένα string και θα επιστρέφει ένα dictionary. Το string αποτελείται από τμήματα χωρισμένα με `;`. Κάθε τμήμα έχει τη μορφή `κλειδί/ακέραιος/ακέραιος/...`. Το κλειδί είναι string και οι υπόλοιπες τιμές ακέραιοι σε λίστα.

Η συνάρτηση θα πρέπει:
```python
print(f("a/2/3;b/6/5;g/88/99")) # Τυπώνει {'a': [2, 3], 'b': [6, 5], 'g': [88, 99]}
print(f("chr1/10/20/30")) # Τυπώνει {'chr1': [10, 20, 30]}
```

### Άσκηση 4

Γράψτε μία συνάρτηση η οποία θα παίρνει σαν παράμετρο ένα string και θα επιστρέφει ένα dictionary από dictionaries. Το string αποτελείται από τμήματα χωρισμένα με `;`. Κάθε τμήμα έχει τη μορφή `κλειδί=[εσω1:ακέραιος,εσω2:ακέραιος,...]`. Τα εξωτερικά και τα εσωτερικά κλειδιά είναι strings. Οι εσωτερικές τιμές είναι ακέραιοι.

Η συνάρτηση θα πρέπει:
```python
print(f("a=[b:4,t:7];t=[b:7,u:99,h:9];u=[b:6]")) # Τυπώνει {'a': {'b': 4, 't': 7}, 't': {'b': 7, 'u': 99, 'h': 9}, 'u': {'b': 6}}
print(f("x=[y:1]")) # Τυπώνει {'x': {'y': 1}}
```

### Άσκηση 5

Γράψτε μία συνάρτηση η οποία θα παίρνει σαν παράμετρο ένα string και θα επιστρέφει ένα dictionary. Το string έχει πολλές γραμμές. Κάθε ομάδα είναι μία γραμμή-κλειδί (string) και αμέσως μετά δύο γραμμές με ακέραιους. Το dictionary αντιστοιχίζει κάθε κλειδί στη λίστα των δύο ακεραίων που ακολουθούν.

Η συνάρτηση θα πρέπει:
```python
print(f("a\n2\n3\nb\n5\n6\nt\n8\n9")) # Τυπώνει {'a': [2, 3], 'b': [5, 6], 't': [8, 9]}
```

### Άσκηση 6

Γράψτε μία συνάρτηση η οποία θα παίρνει σαν παράμετρο ένα string με εγγραφές BED-like και θα επιστρέφει ένα dictionary. Κάθε εγγραφή έχει τη μορφή `χρωμόσωμα:αρχή-τέλος` και οι εγγραφές χωρίζονται με `;`. Το κλειδί είναι το χρωμόσωμα (string). Η τιμή είναι η λίστα `[αρχή, τέλος]` με ακέραιους. Κάθε χρωμόσωμα εμφανίζεται μία φορά.

Η συνάρτηση θα πρέπει:
```python
print(f("chr1:100-200;chr2:50-80;chrX:1-10")) # Τυπώνει {'chr1': [100, 200], 'chr2': [50, 80], 'chrX': [1, 10]}
print(f("chr3:7-9")) # Τυπώνει {'chr3': [7, 9]}
```

### Άσκηση 7

Γράψτε μία συνάρτηση η οποία θα παίρνει σαν παράμετρο ένα string με αναγνώσεις (reads) και θα επιστρέφει ένα dictionary. Κάθε ανάγνωση έχει τη μορφή `όνομα=χρωμόσωμα:αρχή-τέλος(κλώνος)`, όπου ο κλώνος είναι `+` ή `-`. Οι αναγνώσεις χωρίζονται με `;`. Το κλειδί είναι το όνομα. Η τιμή είναι το dictionary `{"chrom": χρωμόσωμα, "start": αρχή, "end": τέλος, "strand": κλώνος}` με `start` και `end` ακέραιους.

Η συνάρτηση θα πρέπει:
```python
print(f("read1=chr1:10-20(+);read2=chr3:5-15(-)")) # Τυπώνει {'read1': {'chrom': 'chr1', 'start': 10, 'end': 20, 'strand': '+'}, 'read2': {'chrom': 'chr3', 'start': 5, 'end': 15, 'strand': '-'}}
print(f("rA=chr2:1-2(+)")) # Τυπώνει {'rA': {'chrom': 'chr2', 'start': 1, 'end': 2, 'strand': '+'}}
```

### Άσκηση 8

Γράψτε μία συνάρτηση η οποία θα παίρνει σαν παράμετρο ένα string με αποστάσεις μεταξύ δειγμάτων και θα επιστρέφει ένα dictionary από dictionaries. Κάθε εγγραφή έχει τη μορφή `δείγμα1,δείγμα2,δεκαδικός` και οι εγγραφές χωρίζονται με `;`. Για κάθε εγγραφή, το εξωτερικό κλειδί είναι το `δείγμα1`, το εσωτερικό κλειδί το `δείγμα2` και η τιμή ο δεκαδικός (`float`). Αν το ίδιο `δείγμα1` εμφανίζεται πολλές φορές, οι εσωτερικές τιμές μαζεύονται στο ίδιο εσωτερικό dictionary.

Η συνάρτηση θα πρέπει:
```python
print(f("A,B,0.1;A,C,0.5;B,C,0.2")) # Τυπώνει {'A': {'B': 0.1, 'C': 0.5}, 'B': {'C': 0.2}}
print(f("X,Y,1.5")) # Τυπώνει {'X': {'Y': 1.5}}
```

### Άσκηση 9

Γράψτε μία συνάρτηση η οποία θα παίρνει σαν παράμετρο ένα string με γονίδια και εξόνια και θα επιστρέφει ένα dictionary από dictionaries. Κάθε γονίδιο έχει τη μορφή `γονίδιο{εξόνιο1:αρχή-τέλος,εξόνιο2:αρχή-τέλος,...}`. Τα γονίδια χωρίζονται με `;`. Το εξωτερικό κλειδί είναι το όνομα του γονιδίου. Κάθε εσωτερική τιμή είναι η λίστα `[αρχή, τέλος]` με ακέραιους.

Η συνάρτηση θα πρέπει:
```python
print(f("geneA{exon1:10-20,exon2:30-40};geneB{exon1:1-5}")) # Τυπώνει {'geneA': {'exon1': [10, 20], 'exon2': [30, 40]}, 'geneB': {'exon1': [1, 5]}}
print(f("g1{e1:2-3}")) # Τυπώνει {'g1': {'e1': [2, 3]}}
```

### Άσκηση 10

### Άσκηση 19

Γράψτε μία συνάρτηση η οποία θα παίρνει σαν παράμετρο ένα dictionary από dictionaries (string κλειδιά, εσωτερικές τιμές ακέραιοι) και θα επιστρέφει ένα string. Είναι η αντίστροφη διαδικασία της Άσκησης 4: κάθε εξωτερικό στοιχείο γίνεται `κλειδί=[εσω1:τιμή1,εσω2:τιμή2,...]` και τα τμήματα ενώνονται με `;`, με τη σειρά των στοιχείων του dictionary και των εσωτερικών dictionaries.

Η συνάρτηση θα πρέπει:
```python
print(f({"a": {"b": 4, "t": 7}, "t": {"b": 7, "u": 99, "h": 9}, "u": {"b": 6}})) # Τυπώνει "a=[b:4,t:7];t=[b:7,u:99,h:9];u=[b:6]"
print(f({"x": {"y": 1}})) # Τυπώνει "x=[y:1]"
```

### Άσκηση 20

Η συνάρτηση θα πρέπει:

